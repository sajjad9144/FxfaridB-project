# FX FARID — ربات روانشناسی ترید

ربات تلگرام برای محتوای روانشناسی ترید. تمام محتوا از پنل ادمین داخل تلگرام مدیریت می‌شود (بدون نیاز به کدنویسی).

## معماری

- **GramIO + TypeScript** — فریم‌ورک ربات
- **PostgreSQL + Drizzle ORM** — دیتابیس
- **حالت A** — ۸ بخش ثابت، محتوای کاملاً قابل ویرایش

### ساختار پوشه‌ها
```
src/
├─ config/        خواندن و اعتبارسنجی متغیرهای محیطی
├─ db/            اسکیما، اتصال، seed
├─ keyboards/     ساخت دکمه‌های شیشه‌ای (inline)
├─ services/      منطق دیتابیس (users, content, consult)
├─ handlers/
│  ├─ user/       start، منو، بخش‌ها، آیتم‌ها، مشاوره
│  └─ admin/      پنل مدیریت
└─ index.ts       نقطه شروع
```

| # | بخش | نوع |

هر بخش محتوایی: یک متن توضیح + لیست آیتم‌ها (لینک یا فایل) با صفحه‌بندی ۵‌تایی.
بخش مشاوره: ویس توضیحات + دکمه «تعرفه» و «ثبت درخواست» (فرم: نام، ایمیل، آیدی تلگرام، توضیح).

## راه‌اندازی

```bash
# ۱. نصب
npm install

# ۲. تنظیم محیط
cp .env.example .env
# فایل .env را پر کن (BOT_TOKEN، DATABASE_URL، ADMIN_IDS)

# ۳. ساخت جدول‌ها
npm run db:push

# ۴. ساخت ۸ بخش پیش‌فرض و تنظیمات
npm run db:seed

# ۵. اجرا (توسعه)
npm run dev

# اجرا (پروداکشن)
npm run build && npm start
```

## متغیرهای محیطی

| متغیر | توضیح |
|-------|-------|
| `BOT_TOKEN` | توکن از BotFather |
| `DATABASE_URL` | رشته اتصال پستگرس |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها، با کاما |
| `CONSULT_CHAT_ID` | (اختیاری) مقصد درخواست‌های مشاوره |

## امنیت
- توکن ربات هرگز commit نمی‌شود (`.env` در `.gitignore`).
- اگر توکن جایی لو رفت، در BotFather `/revoke` بزن و تازه بگیر.
